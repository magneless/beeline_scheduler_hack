# Q&A из чата 3 — сводка

Источник: [QA_raw.md](QA_raw.md).

## Извлечённые сведения

| Тема | Информация |
|---|---|
| Район и участок | Район — географический район Москвы; участок объединяет несколько районов. Бригада может получать заявки из разных районов своего участка. |
| Граница назначений | Перекрёстное назначение бригад между участками запрещено. Ключевое ограничение определяется участком, а не городом. |
| Москва и Подмосковье | Города Подмосковья, указанные в одном CSV-файле с Москвой, относятся к соответствующему участку. Перемещение бригады между Москвой и таким городом допустимо, если обе территории входят в один участок. |
| Новая заявка и неработающий сотрудник | Обычная новая заявка или авария сама по себе не должна автоматически вызывать сотрудника, который по первоначальному плану не работает в этот день. |
| Форс-мажор | При существенном изменении ситуации возможна отдельная эскалация вплоть до привлечения дополнительного сотрудника с выходного. Это не штатный механизм обработки каждой новой заявки. |
