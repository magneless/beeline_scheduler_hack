Привет, вопрос для оргов. Может ли а) авария б) обычная заявка, пришедшая посреди дня, выдергивать бригаду из дома, которая сегодня не работает по изначальному плану на день?

**Данила //ЛЦТ 2026, [24.09.2026 19:49], в ответ Ruslan**

> Привет, вопрос для оргов. Может ли а) авария б) обычная...

В штатном сценарии — нет.

Новая заявка или авария сама по себе не должна автоматически выдёргивать из дома сотрудника, который по первоначальному плану в этот день не работает.

При этом для отдельных форс-мажорных сценариев возможна эскалация вплоть до привлечения дополнительного сотрудника с выходного. Это уже не стандартный механизм обработки каждой новой заявки, а один из возможных способов реакции на существенное изменение ситуации в течение дня.

## Города Подмосковья в составе участка

**Данила //ЛЦТ 2026, [26.09.2026 10:57], в ответ Muginov Rinat**

> Добрый день! Вы недавно писали: Добрый день!...

Добрый день!

Ключевое ограничение действует на уровне участков, а не непосредственно городов.

Города Подмосковья, которые указаны в одном CSV-файле с Москвой, являются частью соответствующего участка. Поэтому перемещение бригады между Москвой и таким городом допустимо, если обе территории входят в один участок.

Между разными участками перекрёстное назначение бригад запрещено.
