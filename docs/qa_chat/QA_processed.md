# Q&A из чата — сводка

Источник: [QA_raw.md](QA_raw.md).

## Извлечённые сведения

| Тема | Информация |
|---|---|
| Приоритеты типов работ | Приоритет распределения: **Авария → Подключение → Ремонт / Дозаказ**. Авария имеет максимальный приоритет. |
| Поступление аварии | Аварийная заявка, поступившая в течение рабочего дня, может стать основанием для изменения ранее сформированного маршрута бригады. |
| Нормативное время дороги | 20 минут нужны для первоначального резервирования времени при постановке заявки в график. При распределении они заменяются реально рассчитанным временем дороги. |
| Изменение времени дороги | На вопрос о замене 20 минут своим расчётом или применении `max(20, расчётное время)` эксперт разрешил замену. Увеличение норматива допустимо, хотя названо редким случаем. |
| Дорога в нормативе аварии | Дорога входит в 100 минут норматива выполнения аварийной заявки. Исходный норматив дороги до ТКД составляет 20 минут. |
| Данные для расчётов | Во всех расчётах и экспериментах используются только файлы с синтетическими данными. Контрольные данные не используются. |
| Район обслуживания | Район — зона охвата бригадами. Один набор бригад не может обслуживать весь город; заявки распределяются между бригадами внутри одного района. |
| Статус бригады | Статус бригады приравнивается к статусу инженера. |
| Нормативы | Предоставлен файл «Нормативы.xlsx». Норматив описывает, сколько времени бригада должна потратить на один вызов. |
| Содержание датасета | Датасет описывает возможности и историю работы каждой бригады. Для тестирования модели предлагается набор синтетических данных. |
| Интеграция | Интеграция с существующими решениями и бизнес-процессами не требуется. Важен подход к решению задачи; прикладной уровень менее значим. |
