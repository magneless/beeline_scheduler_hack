# Q&A из чата 2 — сводка

Источник: [QA_raw.md](QA_raw.md).

## Извлечённые сведения

| Тема | Информация |
|---|---|
| Заправка автомобиля | Время заправки и очереди на АЗС находятся за рамками задачи. Специально моделировать заправку в алгоритме не требуется. |
| Количество оборудования | Фиксированного норматива количества устройств и жёсткого ограничения грузоподъёмности нет. Такое ограничение необязательно; команда может самостоятельно задать разумный предел в своей модели. |
| Запас пешего инженера | Примерно 1–2 устройства в рюкзаке — допустимый модельный ориентир для пешего инженера, а не норматив компании. |
| Потребность в оборудовании | Оборудование требуется не для каждой заявки. |
| Временные окна | В текущем процессе окна фиксированы. Сохранение существующих окон — нормальный базовый сценарий. Эксперименты с изменением окон допустимы, если команда показывает повышение эффективности. |
| Начатая работа и авария | Высокий приоритет аварии не прерывает физически начатую работу. Бригада завершает текущую заявку и после освобождения может быть направлена на аварию. |
| Время реакции на сетевую аварию | Допустимо закладывать ориентировочное время реакции 1–2 часа. При выборе бригады и перестроении маршрута учитываются время появления аварии, текущее состояние исполнителей и требуемое время реакции. |
| Поступление обычных заявок | В течение рабочего дня могут появляться подключения, локальные заявки и другие типы работ, а не только аварии. |
| Добавление обычной заявки | Новую обычную заявку можно добавить в свободный интервал между запланированными работами; она не должна полностью перестраивать уже сформированный план. |
| Перепланирование из-за аварии | Аварийная заявка может привести к перепланированию оставшейся части рабочего дня с сохранением уже начатых работ. |
| Граница региона | Для предоставленных данных один регион соответствует одному CSV-файлу. Московские заявки и заявки из удалённого Подмосковья внутри этого файла относятся к одному региону. |
| Межгородские назначения | Направлять московскую бригаду в Домодедово, Каширу и другие удалённые города, а бригаду из Подмосковья — в Москву допустимо, если это рационально. Специальный запрет таких назначений не нужен. |
| Рациональность маршрута | Нежелательны ненужные многократные перемещения между Москвой и удалённым городом в течение дня, например «Москва → Домодедово → Москва → Домодедово». |
