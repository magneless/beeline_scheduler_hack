# Перерасчёт маршрутов при событиях

Этот документ описывает целевые правила диспетчерского перепланирования по таблице `Recount_Conditions.md`. Перерасчёт касается оставшейся части дня: фактически выполненные поездки и начатые работы сохраняются. Заявки, которые не были назначены **до** события, не участвуют в новом расчёте; новая заявка, вызвавшая событие, участвует.

Подтверждение начала работы, включая опоздание, не запускает пересчёт и не меняет расписание. Прогноз окончания по нормативу сохраняется отдельно от планового времени. После ввода фактического завершения пересчитывается оставшийся маршрут только этой бригады, если завершение позже принятого планового окончания. При завершении вовремя или раньше будущие визиты сохраняются.

| Событие | Изначально неназначенные заявки участвуют | Запускается пересчёт | Начатые задачи прерываются | Задача в пути может измениться | Последующий маршрут обязан учитывать задачу в пути | Диспетчер выбирает исходный или пересчитанный маршрут | Другие запланированные задачи могут быть отменены |
|---|---|---|---|---|---|---|---|
| Авария | Нет | Да | Нет | Да | Нет | Нет | Да |
| Отмена назначенной заявки | Нет | Да | Нет | Нет | Да | Да | Нет |
| Отмена неназначенной заявки, включая «На разбор» | Нет | Нет | Нет | Нет | Расписание сохраняется | Нет, отмена сохраняется сразу | Нет |
| Недоступность инженера | Нет | Да | Нет | Нет | Да | Да | Нет |
| Новая обычная заявка | Нет | Да | Нет | Нет | Да | Да | Нет |
